---

## Metadata

| Header | Direction | Meaning |
|---|---|---|
| `x-api-key` | Laravel to Go, every call except `Ping` | Shared secret |
| `x-publish-events` | Laravel to Go, optional | The value `1` asks the service to publish `stock.changed` for this call. Sent only on the async path |

---

## Event contract

Routing: exchange `ec.events` (topic), routing key `stock.changed`, queue `ec.stock.changed`. Messages are JSON, persistent, with the content type `application/json`.

| Field | Type | Meaning |
|---|---|---|
| `event_id` | string | Unique id, used to drop duplicates |
| `type` | string | Always `stock.changed` |
| `product_id` | integer | Product |
| `stock` | integer, 0 or more | Quantity after the change |
| `deleted` | boolean | The stock record was removed |
| `reason` | string | `set`, `deleted`, `reserved` or `released` |
| `version` | integer | Unix time in microseconds. Larger means newer |
| `occurred_at` | string | UTC time with microseconds |

The consumer rejects a message that is not valid JSON, lacks a field, or carries a negative stock. Rejected messages go to `ec.events.dlx` and then `ec.stock.changed.dlq`.

---

## Changing the contract

1. Keep existing field numbers and names. Add new fields with new numbers, or new optional JSON fields.
2. Regenerate the PHP classes into `ECBackend/app/Grpc` for the gRPC file. The Go code is regenerated by the Docker build or `make proto`.
3. Update the publisher in `ECInventory/internal/events` and the validation in `StockEventHandler` together.
4. Run `go test ./internal/...` in `ECInventory`, `php artisan test` in `ECBackend` and `npm test` in `ECWeb`.
5. Commit the contract and every implementation together.
